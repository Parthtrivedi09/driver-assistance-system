Annotation files  (INSIDE gt.txt)
    What annotation file looks like:

    Example:

    00000.ppm;774;411;815;446;11
    🧠 Meaning:
    Field	Meaning
    filename	image name
    x1, y1	top-left corner
    x2, y2	bottom-right
    class	sign type


1. convert GTSDB to YOLO format
    YOLO format looks like 
        For each image
            class_id center_x centr_y width height
            All value normalized to 0 to 1
