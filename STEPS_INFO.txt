Annotation files  (INSIDE gt.txt)
    What annotation file looks like:

    Example:

    00000.ppm;774;411;815;446;11
    🧠 Meaning:
    Field	Meaning
    filename	image name
    x1, y1	top-left corner of the bounding box
    x2, y2	bottom-right of the bounding box
    class	sign type


1. convert GTSDB to YOLO format (Something which YOLO understands)
    YOLO format looks like 
        For each image

            class_id center_x centr_y width height (This is what YOLO wants)

            All value normalized to 0 to 1

            How we will convert?
                CENTER COORDINATES
                    center_x = (x1 + x2) / 2 / image_width
                    center_y = (y1 + y2) / 2 / image_height


    After this raw data got transformed to YOLO-compatible training format

2. After converting the images to the proper YOLO format with separately having the labels in text folder
   so now we will split the data into validation and training data
   

3. YOLO CONFIG (data.yaml) (YAML- Key-Value Pairs: Represented as key: value)
    YOLO needs a config file to understand
        Where your data is
        What classes exist
    Think of it as -> Instruction file for the model

    Basically it consists of key value pair
    
4. Training an object detection model using transfer learning (FINE TUNING)
        YOLO already knows general objects you teach it WHAT A TRAFFIC SIGN IS?
            #here we are fine tuning a pretrained YOLO model on a custom traffic dataset
            #basically the model already knows about car people etc we are simply using transfer learning (FINE TUNING) to use that pre trained model
            from ultralytics import YOLO

            def train_model():
                model = YOLO("yolov8n.pt")

                model.train(
                    data="data/processed/data.yaml", # this is the configuration file where we have mentioned every location and key value pairs
                    epochs=20,
                    imgsz=640,
                    batch=8
                )

            if __name__ == "__main__":
                train_model()




-> HOW YOLO IS WORKING??
     1. YOLO converts the image into a grid each grid cell is responsible for detecting object inside it\

     2. For each cell YOLO predicts (x,y,w,h) + class + confidence

     3. From gt.txt consisting of the true label and true bounding box sizes 
        new YOLO compares the prediction with the actual box and class
        and finds the error
         there are majorly 3 different errors
            1. BOX LOSS “How far is predicted box from actual box?”
            2. CLS LOSS “Did I predict the correct class?”
            3. DFL LOSS “How precise is the box boundary?”

     4. How model learns??
            Predict
            Compare with ground truth
            Calculate total loss
            Backpropagation
            Update weights
    EVERY SINGLE STEP OF YOLO
        YOLO PIPELINE (ONE-LINERS)
            Input image → pass through CNN backbone → extract features
            Features → processed at multiple scales (neck)
            Model predicts many bounding boxes + class probabilities (head)
            Filter low-confidence predictions
            Apply Non-Max Suppression to remove duplicate boxes
            Compare predictions with ground truth (gt.txt)
            Compute losses (box + class + dfl)
            Backpropagate error to update weights
            Repeat over batches and epochs → improve predictions
